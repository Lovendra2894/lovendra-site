# lovendra.dev

Personal site. Static HTML, no build step, no dependencies.

- `index.html` — the whole site (styles inline, fonts from Google Fonts)
- `Lovendra_Gupta_Resume.pdf` — linked from the footer

## Deploy

Hosted on Vercel. Every push to `main` deploys automatically.

## Local preview

    python3 -m http.server 8000

Then open http://localhost:8000
